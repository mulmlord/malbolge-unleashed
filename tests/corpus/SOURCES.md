## Generated by CC0 software

`stringout_hello.mal` and `stringout_malbolge.mal` are the output of Matthias Ernst's
`stringout.c` (https://web.archive.org/web/20200625001041/http://matthias-ernst.eu/malbolge/stringout.c),
which carries the header "To the extent possible under law, the author has dedicated all copyright
and related and neighboring rights to this software to the public domain worldwide" (CC0 1.0). They
were produced by us, not copied from his page:

    printf 'Hello World!\n' | ./stringout > stringout_hello.mal
    printf 'Malbolge: 0123456789 [ok]\n' | ./stringout > stringout_malbolge.mal

## Own work (CC0 / public domain, like the rest of this repository's fixtures)

| File | What it is |
|---|---|
| `encrypt_fault.mal` | 3 cells, normalized `/<p` (In, Out, Opr), loader text `ub<`. Echoes one byte, then `Opr` at `D == C` overwrites the cell about to be encrypted with a value outside 33..126: `E_ENCRYPT` at step 3. In the reference this is out-of-bounds `xlat2` indexing (UB). Stands in for mtve's `answer.mal`, which is not included. |
| `exec_fault.mal` | 3 cells, normalized `/<o`, loader text `ubB`. Echoes one byte, then runs off the end of the program into the fill, where `[C]` is outside 33..126: `E_EXEC` at step 4 (the reference hangs). |
| `loader_bug.mal` | `../programs/hello.mal` with the byte at offset 10 replaced by `0xFF` (same length, so no later cell shifts). The reference loader accepts it unchecked (the bug that Scheffer's `copy.mal` exploits; the program then hangs); classic mode rejects it: `E_LOAD` at offset 10. Stands in for `copy.mal`, which is not included. |
| `cat_typo.mal` | `../programs/cat_nostop.mal` with the last character `%` replaced by `k`. The MalbolgeLISP README prints its cat this way (a transcription error); the reference loader rejects it ("invalid character"), classic mode: `E_LOAD` at byte offset 65. The README itself is not used (see "Not included"). |
| `*.in` | stdin fixtures: `cat.in` (`Hello, world!\n`, NUL, 0xFF, 0x80, `end`), `echo_x.in` (`x`), `truth_0.in` (`0`), `truth_1.in` (`1`) |
